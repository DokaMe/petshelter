# Где нажать в Битрикс24, чтобы получить вебхук

Понадобится учётная запись сотрудника, которому доступно чтение карточек питомцев в CRM. REST выполняет запросы с правами владельца вебхука. [Официальная инструкция Битрикс24](https://apidocs.bitrix24.ru/first-steps/first-rest-api-call.html)

## Создание

1. Откройте портал заказчика и в левом меню выберите **Разработчикам**.
2. Откройте **Готовые сценарии → Другое → Входящий вебхук**.
3. В блоке **Настройка прав** добавьте **CRM** (scope `crm`).
4. Скопируйте полный адрес из поля **Вебхук для вызова REST API**. Вставьте его в `backend/.env` в строку `BITRIX24_WEBHOOK_URL=`. Секрет уже входит в адрес.
5. Нажмите **Создать**. Вебхук появится во вкладке **Интеграции**.

Храните адрес в серверном `.env`. Вебхук даёт доступ от имени сотрудника, поэтому уберите его из скриншотов, переписки и исходного кода. При утечке обновите секрет в карточке вебхука и замените адрес в `.env`.

Если пункт **Входящий вебхук** отсутствует, администратор может проверить **Настройки Битрикс24 → Безопасность → Интеграции Битрикс24** и поле **Кто может создавать входящие вебхуки**. Если портал предлагает подключить REST API, доступ зависит от его подписки. [Права и доступ к REST API](https://helpdesk.bitrix24.ru/open/20886106/)

## Где взять ID и коды полей

Откройте сохранённый вебхук во вкладке **Интеграции**. В его блоке **Генератор запросов** выберите метод, заполните параметры и нажмите **Выполнить**.

1. Метод `crm.type.list` покажет список типов. В `result.types` найдите смарт-процесс с карточками питомцев по `title`. Скопируйте его `entityTypeId` в `BITRIX24_ENTITY_TYPE_ID`. [Список смарт-процессов](https://apidocs.bitrix24.ru/api-reference/crm/universal/user-defined-object-types/crm-type-list.html)
2. Метод `crm.item.fields` с параметром `entityTypeId` покажет `result.fields`. По подписи найдите поля вида, пола, возраста, породы, описания и фото. Скопируйте их ключи из ответа в `BITRIX24_FIELDS`. [Поля карточки](https://apidocs.bitrix24.ru/api-reference/crm/universal/crm-item-fields.html)
3. Метод `crm.item.list` с тем же `entityTypeId` покажет, как значения реально приходят. Для полей типа «Список» сверьте ID выбранных вариантов со справочником поля. Для поля «Фото» проверьте, что приходит объект с `id` и `urlMachine` или массив таких объектов. Для пристроенного питомца скопируйте его `stageId`. [Карточки CRM](https://apidocs.bitrix24.ru/api-reference/crm/universal/crm-item-list.html) · [Скачивание фото](https://apidocs.bitrix24.ru/api-reference/files/how-to-download-files.html)

Затем заполните остальные строки `.env` и выполните первый импорт. [Настройка и запуск в Pet Shelter](BITRIX24_SETUP.md)
