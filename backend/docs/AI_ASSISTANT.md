# Как ИИ-помощник отвечает на вопросы об окрасе

Ищите питомца по цвету или спрашивайте об уже выбранной карточке. Например, можно написать «Есть ли серые кошки?» или после выбора Барсика спросить «Какого он цвета?».

## Откуда берётся вопрос

1. Обработчик отправки в [frontend/src/chat.ts](../../frontend/src/chat.ts) читает текст из поля чата и вызывает `api.sendMessage(sessionId, text)`. После анкеты тот же файл отправляет готовый запрос «Помоги подобрать питомца по моей анкете». Если человек открыл чат из карточки, фронтенд передаёт её ID в `selected_animal` при создании диалога.
2. Клиент в [frontend/src/api.ts](../../frontend/src/api.ts) отправляет `POST /api/chat/conversations/<session_id>/messages/` с JSON `{"content":"Какого он цвета?"}`.
3. `ChatMessageListCreateView.post()` в [backend/chatbot/views.py](../chatbot/views.py) проверяет владельца диалога, валидирует сообщение и передаёт исходный текст в `answer(conversation, content)`.

## Как Django собирает запрос к модели

В [backend/chatbot/assistant.py](../chatbot/assistant.py) функция `answer()` собирает массив `messages`:

- В сообщении с ролью `system` лежат инструкции боту.
- Следом идёт блок данных с приютом, видом животного, целью, анкетой, ID выбранной карточки и каталогом. В выборку попадает до 30 доступных животных из приюта с учётом вида в диалоге. Выбранная карточка получает приоритет при выборке.
- Затем идут до десяти последних реплик диалога, от старой к новой.
- Последнее сообщение с ролью `user` содержит сам вопрос пользователя.

[backend/chatbot/openrouter.py](../chatbot/openrouter.py) отправляет этот массив в OpenRouter. Для текстовых запросов используется `OPENROUTER_MODEL`, для запросов с фотографиями и команды анализа — `OPENROUTER_VISION_MODEL`. По умолчанию используется `deepseek/deepseek-v4.1-flash-1017`. При смене модели для фото проверьте её поддержку изображений. [Документация OpenRouter по входным изображениям](https://openrouter.ai/docs/guides/overview/multimodal/image-understanding)

## Какие инструкции получает бот

Бот отвечает по-русски. В режиме друга он обращается на «ты», в режиме консультанта на «вы». Он учитывает анкету и отвечает о питомцах из переданного каталога. Данные карточек и история диалога служат контекстом.

Для вопросов об окрасе бот сначала использует значение, которое указал приют. Если такого значения нет, он использует сохранённое описание окраса с фотографии или анализирует приложенный кадр. Когда вывод сделан по изображению, бот так и пишет. Правила из [backend/chatbot/coat.py](../chatbot/coat.py) велят учитывать только шерсть, различать основной цвет, полосы и пятна и сообщать о неопределённости при плохом освещении. По окрасу бот не определяет породу, пол или здоровье.

При подборе он учитывает синонимы и различает «однотонный чёрный» и «чёрный с белыми пятнами». Если пользователь спрашивает «Какого он цвета?», модель получает ID выбранной карточки. При нехватке сведений бот должен сказать, что окрас неизвестен.

Модель возвращает JSON с `answer` и `animal_ids`. Django пропускает максимум три уникальных ID из переданного каталога, сохраняет вопрос и ответ в истории и возвращает карточки. Фронтенд отображает ответ бота и рекомендованных питомцев.

## Как заполнить окрас в карточках

- В Django-админке сотрудник может заполнить «Окрас от приюта». Это значение имеет приоритет.
- Команда `detect_animal_coats` отправляет фото в OpenRouter и сохраняет результат вместе с именем обработанного файла. Когда фото заменяется, старое описание перестаёт использоваться.
- На вопрос об окрасе или сразу после него Django может приложить до четырёх ещё не обработанных фотографий. Так бот умеет отвечать по новому фото сразу после загрузки. Этот ответ относится к текущей реплике. Чтобы окрас появился в самой карточке, укажите его в админке или запустите команду.

Из корня локального репозитория:

```bash
.venv/bin/python backend/manage.py detect_animal_coats
.venv/bin/python backend/manage.py detect_animal_coats --animal-id 42
```

Команда обрабатывает записи с фото без указанного приютом окраса и пропускает уже обработанные файлы. Флаг `--force` повторяет анализ актуальных фото.
