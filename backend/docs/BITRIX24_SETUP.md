# Подключение каталога Битрикс24 к Pet Shelter

Django читает карточки из смарт-процесса CRM Битрикс24, сохраняет их в свою базу и отдаёт через `/api/animals/`. Веб-виджет и вкладка «Мои подопечные» используют один каталог. Команда читает Битрикс24 и записывает изменения в Django.

Импорт настроен для **смарт-процесса CRM**, где один элемент соответствует одному питомцу. Подключайте процесс с карточками, которые разрешено показывать посетителям сайта. Если заказчик хранит питомцев в торговом каталоге или универсальном списке, понадобятся методы этого раздела Битрикс24. [Элементы CRM](https://apidocs.bitrix24.ru/api-reference/crm/universal/crm-item-list.html) · [Варианты хранения файлов](https://apidocs.bitrix24.ru/api-reference/files/how-to-download-files.html)

## Что заполнить в `backend/.env`

Сначала получите URL входящего вебхука, ID смарт-процесса и коды полей. [Пошагово по интерфейсу Битрикс24](BITRIX24_WEBHOOK.md)

| Переменная | Что вписать |
| --- | --- |
| `BITRIX24_WEBHOOK_URL` | Целый адрес из поля «Вебхук для вызова REST API». Он включает домен, ID пользователя и секрет. Имя метода и параметры к адресу добавляет Django. |
| `BITRIX24_ENTITY_TYPE_ID` | Число `entityTypeId` нужного смарт-процесса. |
| `BITRIX24_SHELTER_ID` | Числовой ID приюта в Django. Его видно в `/api/chat/shelters/` и в адресе страницы приюта в админке. Одна настройка импорта соответствует одному приюту. |
| `BITRIX24_FIELDS` | JSON с кодами полей из `crm.item.fields`. Обязателен `species`. Дополнительно можно задать `gender`, `age`, `breed`, `description` и `photo`. Кличка берётся из `title`. Для `photo` нужен тип «Файл». |
| `BITRIX24_SPECIES_MAP` | JSON со значениями поля вида. Например, `{"101":"cat","102":"dog"}`, если Битрикс24 возвращает ID вариантов списка. Значения «Кошка», «Кот», «Собака», `cat` и `dog` распознаются напрямую. |
| `BITRIX24_GENDER_MAP` | JSON со значениями пола. Например, `{"201":"самец","202":"самка"}`. Текст «самец» и «самка» распознаётся напрямую. |
| `BITRIX24_ADOPTED_STAGE_IDS` | Один или несколько `stageId` пристроенных питомцев через запятую. Остальные стадии попадают в каталог как «Ищет хозяина». |

Пример с вымышленными значениями. Используйте коды полей ровно в том виде, в каком они пришли в `crm.item.fields`, например `ufCrm2_123`. [Поля элементов CRM](https://apidocs.bitrix24.ru/api-reference/crm/universal/crm-item-fields.html)

```dotenv
BITRIX24_WEBHOOK_URL=https://portal.example/rest/25/ВАШ_СЕКРЕТ/
BITRIX24_ENTITY_TYPE_ID=1050
BITRIX24_SHELTER_ID=1
BITRIX24_FIELDS='{"species":"ufCrm2_123","gender":"ufCrm2_124","age":"ufCrm2_125","description":"ufCrm2_126","photo":"ufCrm2_127"}'
BITRIX24_SPECIES_MAP='{"101":"cat","102":"dog"}'
BITRIX24_GENDER_MAP='{"201":"самец","202":"самка"}'
BITRIX24_ADOPTED_STAGE_IDS=DT1050_1:SUCCESS
```

## Первый импорт

Из папки `backend` выполните:

```sh
../.venv/bin/python manage.py migrate
../.venv/bin/python manage.py sync_bitrix_animals --dry-run
../.venv/bin/python manage.py sync_bitrix_animals
```

`--dry-run` проверяет доступ, поля и карточки. Фото скачиваются при запуске импорта. Если поле содержит несколько файлов, в карточку попадёт первый. Поддерживаются JPEG, PNG и WebP размером до 10 МБ. Django сохраняет их в `media/animals/bitrix/` и выдаёт обычные адреса `/media/…`. [Скачивание файлов из поля CRM](https://apidocs.bitrix24.ru/api-reference/files/how-to-download-files.html)

Повторный запуск обновляет карточку по адресу портала, типу сущности и ID записи. Подопечные остаются привязанными к той же карточке. Удаление карточки в CRM требует отдельного решения, команда сохраняет уже импортированные записи. Для регулярного обновления запускайте эту же команду по расписанию на сервере проекта.

При ошибке команда указывает метод или ID проблемной карточки. Проверьте настройки и запустите импорт повторно. Реальный портал, его поля и права проверяются при первом подключении.
